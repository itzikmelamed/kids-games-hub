# משחקי הנסיכות והחיות (Kids Games Hub)

משחקים חינוכיים לילדים בני 4-5: חיות, נסיכות, אותיות עבריות ומספרים.

- 🎨 בונים עולם - צורות, צבעים ומדבקות + משימות קוליות
- 🎈 בלונים - פיצוץ בלונים לפי אות, צבע או מספר
- 🧠 משחק זיכרון - זוגות חיות ונסיכות
- 🍎 חנות הפירות - ספירה ומיון 1-10
- 🔤 אותיות - לימוד הא"ב + משחק
- 🔢 מספרים - ספירה בקול + משחק

קריינות בעברית דרך Web Speech API. ללא פרסומות, ללא קישורים חיצוניים, ללא איסוף מידע. עובד אופליין (PWA).

Static site, no build step. Deploy: any static host (Vercel).
